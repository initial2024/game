### 规则与长期测试

- 三种难度 × 三个种子分别模拟 1000 个季度，逐步检查状态合法性和债务限额。
- 四种国家规模 × 三种世界格局分别运行 1000 个季度；腐败始终存在。
- 同种子和相同行动逐条重放 1000 次，序列化世界完全相同；连续时间另有两份状态推进 1000 × 90 日的确定性验证。
- 并行订单上限、预留资金、取消仅退 80%、建设精确工期、不可重复提交版本号。
- 人物衰老、死亡后不复任、地方官继任、家族死亡年龄冻结、成年与自愿条件。
- 三条办案路线具有可测试的差异；隐藏身份不能审计定罪；伪证案件不能判有罪；证据不能反复刷取。
- 严格拒绝未知 AI 字段、非法指令、越界地区、空命令及超预算组合；隐藏身份上下文不包含君主真名和案件真相。
- 33 个事件均有满足触发条件的样本、非空规则效果和冷却；并非声称它们都会在任意普通开局自然发生。

### 实际界面与持久化

测试通过触控语义操作真实 Compose 页面：出发微服巡游 → 自动抵达 → 集市探访 → 暗访取得收费凭据 → 验认身份 → 核验账册 → 依法审理 → 返回朝廷 → 等到下一次季度记账 → 看到新任地方官与地方属性变化，最终数据库与当前世界完全一致。

另一条流程使用中文自由文本“兴修水渠”，在软键盘出现后操作预览与确认，检查项目确已登记，并进入朝政、世界、宗室、档案与模型弹窗。验证尺寸为 390×844、density 160；这不覆盖全部手机尺寸、超大字体和系统键盘组合。

存储测试覆盖重复事务拒绝、关闭并重新打开数据库、不同存档隔离、快照恢复、导入导出与篡改拒绝。模型损坏测试覆盖无效 GGUF 头；官方完整文件另外经过 SHA-256 验证。尚未对每一种内部损坏 GGUF 做模糊测试。

模拟器桌面 Quickstep 曾有 ANR 弹窗遮图。CI 专用代码清理桌面进程，并要求活动窗口确为游戏后再截图；该清理操作不进入游戏发布代码。当前交付截图来自最后一次通过的测试，未用设计图替代实机画面。

## 真实模型实测

设备是 GitHub Actions KVM Android 模拟器：Android 15 / API 35、x86_64、Pixel 4 配置、2 个虚拟 CPU、可见 RAM 2,532,896 KiB（约 2.42 GiB），测试画面 390×844。主机 CPU 不固定。**不是 vivo、不是 ARM64 实机，也不是 Android 16 的运行性能。**

模型：Qwen2.5-0.5B-Instruct Q4_K_M，Apache 2.0；491,400,032 字节，SHA-256 `74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`。固定上游版本与链接见 ModelManager.kt / THIRD_PARTY.md。推理：CPU、2 线程、512 上下文。

| 观测项 | 最后一次结果 | 测量边界 |
| --- | --- | --- |
| 原生 load 调用 | 244 ms | 已部署并先校验文件，可能热缓存；不包含下载、复制、哈希；不是首次冷启动总耗时 |
| 短问候生成 | 9733 ms，输出“你好！” | 含提示处理；上限 12 tokens 不代表实际生成数，不能据此计算 tokens/s |
| 中文叙事 | “澄江工厂在三季后建成，耗资140万两。” | 仅为小样本，不能证明全面叙事质量或全部事实约束 |
| 结构化政策 | `{"commands":[{"type":"FARM","region":0}]}`，校验通过 | 强模板提示下的单个意图；不等于复杂自然语言解析全面验收 |
| PSS 采样 | 690,043 KiB，约 674 MiB | 单次进程采样，包含测试框架和界面，非 PSS 峰值 |
| VmHWM | 794,464 KiB，约 776 MiB | /proc/self/status 的本次测试进程最高常驻 RSS，包含模型、界面和测试开销，不是模型独占内存或手机峰值 |
| VmRSS | 791,184 KiB | 卸载前的常驻 RSS 采样 |

连续多次真实推理、取消推理、取消后重新生成与卸载均通过。专项测试总耗时约 138 秒，不等于数百次推理或整日运行稳定性验收。

两组 Android 测试均先关闭模拟器 Wi-Fi 与移动数据，记录的开关值均为 0，再执行规则/UI/存储测试及已部署模型的推理。模型下载发生在关闭来宾网络之前；断网后的搜索按钮不可用是预期行为。这验证本地路径，但不代替手机飞行模式和厂商后台管理测试。
