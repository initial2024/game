# 世界舆图 v4 原生接入

## 工程与回退

目标仓库：initial2024/game；开发分支：feature/world-map-v4；[Draft PR #1](https://github.com/initial2024/game/pull/1)。原工程已包含 Kotlin/Compose 游戏、连续时间、SQLite 存档、规则、巡游、案件和 llama.cpp 推理，因此本次直接接入真实游戏，没有建立另一个游戏或修改其他项目。

集成起点为 adba385，原始地图回退基线为 cf16ae0。提供包里的 HTML、两个场景 JSON、接口说明和任务说明完整保留在 integration/map-v4/upstream。原 HTML SHA-256：`c9a37028576eeceb387079fb6627f189b59d6d19014d72473bae1c56e21b852f`。实际应用使用 app/src/main/assets/maps 中的适配版；保留原绘制器、海岸、相机、地形、查询和主题，没有重画替代地图。

## 游戏与沙盘

世界 → 打开世界舆图 v4 进入原生全屏地图。顶部保留返回、沙盘、时间和倍速；选择城市可查看原生地区信息、官员、巡游与案卷入口，或预览规则行动。国家/地区/城市的稳定 ID 与显示名分离。

- 正式地图：数据库的只读表示与地点选择器。不能从网页直接改资金、军队、证据、人物或归属。
- 地图沙盘：同一 v4 渲染器的编辑模式，保留圈地、修改展示归属、独立剧情槽位、旧参考名开关和 JSON 导入导出；编辑不写入游戏世界。
- JSON 导入：Android 文件选择器，1 MiB 上限，先通过 Kotlin 校验，再确认导入沙盘；同 ID 替换会明确说明。正式游戏不从地图 localStorage 恢复国家状态。
- JSON 导出：通过 Android 文件创建器导出地图表示。完整游戏备份仍在档案中导出，包含规则状态与历史。

游戏存档最多8槽，沙盘使用独立演示缓存；相机、主题、字号和图层缓存只属于辅助界面设置。缺少地图数据的旧游戏不会被空白网页缓存覆盖。

## 可信状态与协议

World 增加可选 cartography 和 setting 字段，不改 SQLite 表结构，不重建用户数据库。旧 JSON 缺省字段分别为 null 和工业初兴。首次读档不会立即重写旧存档；地图所需基础地区坐标可从既有世界派生，首个地图业务行动再写入结构化地图数据。

MapSnapshotMapper 将数据库提交后发布的 World 映射为 chronicle-map-scenario/v2。sceneId 为当前槽位 game-slot-N，revision 使用游戏事务版本，不使用季数或现实时间。基础地名来自当前世界，四地区、三邻国与对应疆域均有稳定 ID，行政层级使用 groups 父子关系和 memberIds。

MapDeltaDispatcher 属于单个 WebView 实例：首次/切换槽位/地理包变化发送全量 applyScenario；相同场景的新版本使用 applyWorldDelta。已发送版本不再重复发送，JS 再次检查 sceneId 与严格递增 revision。JSON回调只确认数据已接收，0.2.1须再收到JS实际绘制状态并通过WebView可见状态回调后，才确认场景ID与版本就绪；失败重置发送器并报告错误，返回重开可从数据库全量恢复。不得在事务提交前推送推测结果。

新增原生规则：

| 行动 | 条件与真实结果 |
| --- | --- |
| 城邑更名 | 地区与稳定地点存在、名称合法；5万两、办理1日，旧历史保留 |
| 营建新邑 | 每地区一个预设可建节点；120万两，登记规划中，120日后验收为现存，不瞬间完成 |
| 修复旧城 | 首个示范旧津，须处于废墟/废弃；80万两、90日，完成前处于规划中 |
| 议定边地移交 | 与东部邻国关系至少80、边地仍属对方；180万两、办理90日，完成时复核，移交后关系-15、每季驻防5万两 |

地图选择本身不执行这些行动；均进入原生确认、规则校验、资金/工期与 SQLite 提交。边地移交是已定义的和平条约规则，不冒充完整战争。其他城邑毁坏/废弃/隐藏状态与不同地理包在协议和校验层支持，尚未全部接入自然灾害/战争触发链。

## WebView 安全

使用 AndroidX WebViewAssetLoader 的 https://appassets.androidplatform.net/assets/maps/chronicle_world_map_v4.html。只允许这一受信文件的本地 GET，其他资源请求返回403，外部导航拒绝。禁用 file/content 访问、跨文件 JS、混合内容、多窗口、定位和网页权限；地图 CSP 禁止网络、iframe、插件与表单提交。

ChronicleHost 是 WebMessageListener，限定 appassets origin、主框架和当前受信页面；没有 addJavascriptInterface。选择消息只接受场景与稳定 ID，原生再次校验当前存档及目标存在，未知字段/业务命令/其他存档 ID 都被拒绝。导入、导出消息只能打开受控原生文件流程。

完整快照和增量通过 JSON 序列化、JSONObject.quote 和 U+2028/U+2029 转义传入固定 JS 方法，绝不拼入裸用户字符串。地图使用 textContent 显示名字。原生和 JS 两侧检查 ID、数量、引用、循环行政层级、经纬度、顶点、退化/自交/重叠多边形。

组件在正尺寸布局后加载页面，布局变化后刷新画布；不允许把零尺寸下的页面就绪当成地图可用。进入后台暂停 WebView，销毁时移除桥、停止加载并 destroy；渲染器退出保留原生存档并给出重开入口。没有全局持有 Activity/WebView 的单例。

## 古代与工业开局

新建界面可选古代王朝或工业初兴，新建默认古代王朝，旧存档保留工业初兴。古代使用府城、手工业、官营作坊、格物、驿道与冷兵器设定；WORKSHOP 与 FACTORY 是不同受时代校验的指令，成本分别为100/140万两，均需270日工期。古代自由命令拒绝直接建设铁路、电力等近现代设施，AI 提示和展示过滤约束同一时代。发展数值代表本时代内的相对水平，达到100不会自动切换工业时代。

这不是完整历代制度模拟：君主继承、兵种装备、朝代特定法制与时代跃迁仍在后续范围。

## 已知地理边界

原内置海岸是简化东亚参考，不是考证历史国界。custom 是经度55–155、纬度-4–65的局部投影和平坦陆地多边形，不能冒充全球引擎；不支持孔洞、共享拓扑、跨日界线和高程包。routes 仅为逻辑示意连线，巡游仍使用现有地区旅行计时，不是沿地图地形寻路。

自定义地理可在沙盘导入查看，也可由有效的完整游戏存档 cartography 提供；本版未做从沙盘一键覆盖正式游戏地理的功能。沙盘编辑不登记游戏规则事实。
