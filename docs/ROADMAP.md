# 后续开发与已知边界

## 当前可玩底座

连续时间、暂停、1×/4×/16×/64×；最多三项并行办理，预留资金和取消退款；四地区、三邻国、33个因果事件，按季度后台记账；规则计算、案件事实、人物生死和世界状态独立于模型。

一个真实的澄江案件支持公开巡幸、隐藏身份调查、远程监察三条路线。国家规模和世界格局是独立开局轴；腐败和派系不会因为选择和平建设或超级大国而关闭。当前阴谋内容为有明确参与者条件的结党阻挠事件，尚非完整的隐秘组织与计划网络。

君主、纪元、预备子女名和出生后子女名可修改。基础家族流程检查成年、自愿、年龄、健康和关系条件；未实现完整婚配、多伴侣、亲属派系、君主衰老与继承。宗室孕期、出生与照护成本由规则登记。

## 下一阶段优先项

1. vivo Android 16 / ARM64 实机验收：安装与覆盖更新、模型加载、峰值内存、温度、速度、后台恢复、长时间推理和低内存降级。当前模拟器数据不代表手机表现。
2. 模型内置自测与更可靠的推荐：区分内存预算、真实加载成功和本机吞吐，保留模型质量评估。0.5B Q4已做模拟器推理，目录中的Q3和1.5B尚未逐个实测。
3. 独立推理适配接口、可持久化的AI演绎与摘要、更多自由文本意图和地方动态对话；保留严格校验与可玩降级。
4. 中央官职与君主继承：保留亡者身份，生成新任者，允许有资格的成年继承人接班；继承争议与派系支持由规则结算。
5. 战争模块：动员、军需、战线、有限战争目标、伤亡、停战与条约。当前烽火边疆只有战备成本、外交压力和边境劫掠，不能宣称完成领土战争。
6. 阴谋网络：动机、参与人、目标、筹备进度、资金、知情范围、线索可信度与反制。查到线索不等于定罪；AI不能自行登记证据或发动政变。
7. 多地区案件与四级腐败：基层、地方、军需、中央的独立账目、官商关系、审计链、诬告与司法程序；区分行政撤换和刑事认定。
8. 长期人物关系、摄政授权、事件链、更多地区政策、经济破产恢复路线与平衡；完善多存档管理、统计图与可选本地通知。

## 交付约束

包名固定为cn.chronicle.shanhe。私钥不进入公开仓库。正式签名Secrets按用户决定后续接入；当前APK分支使用固定开发证书，Actions的日常产物是CI测试签名，两种包不应混作同一签名更新。

模型权重与APK分离，不强制下载、不使用付费推理API。存档不上传外部服务；测试报告中的世界和日志来自自动化新建的合成测试数据。

已使用用户新提供的世界舆图 v4 集成包在同一游戏中开发地图模块，原 tianxia-yutu.html 未作为地图基线。当前进度、测试范围与限制以 MAP_V4_INTEGRATION.md / MAP_V4_TESTING.md 为准；完整地形寻路、城市战损链和全球投影仍属后续范围。
