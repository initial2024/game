## 不得丢失的决定

- 只在 `initial2024/game` 开发同一款原创原生游戏，不改 DSH、Local Dream、Orbit Mail 等其他项目。固定包名、ARM64、签名身份，私钥不入库，不删除玩家数据。
- 确定性规则先结算，本地 AI 后叙事；模型不能改资源、生死、案件真相、身份知情、组织、地区和历史。任何重要变化都通过预定义指令严格校验。
- **后来的“不要回合制、可选倍速”覆盖最初回合制设计。** 季度是内部记账周期，不能变回“下一回合”，也不能给普通聊天收费或设置等待。
- 无模型可玩，模型和 APK 分离，不依赖付费 API，不自动下载大模型或上传玩家存档、聊天。
- 使用用户最后上传的 `chronicle_world_map_v3_2.html`，在原图上升级协议；不能换成细节更少的重画地图。
- GitHub 简介和主 README 英文，保留中文入口；没有要求将游戏中文界面改成英文。
- 《历史时代》是实际策略游戏；Tianming / 东方末日仅参考玩法，检查时无可识别仓库许可证，不能复制未授权代码、美术或商业资产。
- 非性政治强制可以有反抗、敌意、申诉和制度代价；备孕仍独立开关、默认关闭，须成年、自愿及健康等条件。不限年龄性别的非性偶遇、招揽、义亲也必须符合对应身份资格。
- 可自主开发、测试、执行 CI、修复和交付开发 APK；不得冒充真机结果、伪造模型推理或未经确认商业发布。

## 完工标准

先完成 A01/A02，并用从未加载状态开始的压缩版真实 GGUF 聊天验收。随后按 P1/P2 做可玩纵向闭环，持续编译交付，不能只写策划。每项“完成”须有源码路径、合适证据和边界；随机组合不冒充独立故事。最终复验巡游案、战略、人物模型聊天，并严格分开浏览器、模拟器、手机。缺真机/私钥/许可只阻断对应验收，保留可运行成果并继续其他授权工作。
