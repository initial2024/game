# 0.4.1：人物交流、旨意、人才与宫廷军政

本次是同一原生游戏的增量更新，保持包名和开发签名，保留原地图、连续时间及倍速。对话免费、即时结算，不设置游戏时间冷却。AI生成的运行保护截止时间不属于付费或聊天额度。

## 已实现的实际规则

- 所有在世、已登记的Person均使用同一对话入口和同一本地模型适配器；远方人物可通过通信交流。已故人物只读历史。当前默认世界237名人物：原10人、73名府县长官、154名副官和主簿。每名人物有独立稳定ID、信任、忠诚、怀疑、敌意、经历与对话档案。
- 修正以前整类话题终身只结算一次的问题。不同内容在同一经历下可有四次递减的关系收益，重复文本（忽略标点、数字及“您/你”差异）不重复增加关系；新经历可更新话题背景。闲谈主要影响信任，隐匿身份不增加对君主的忠诚。质询、威胁可能降低关系。界面显示本次实际数值变化，历史保留命令原文和规则事件。
- 每条完整对话均可“拟为旨意”，先编辑原文，再生成严格白名单的行动预览，最后确认。支持现有国家政策、地方建筑、审计、赈济、派学、科举、招贤、指定现有人物的地方任命或军队统帅任命、宫廷工程。预览明确实际辖区/对象、费用、工期与未执行内容。否定、疑问、条件与未经证据审理的定罪不直接执行。原始对话和AI意见不会自动变成政令。
- 人才入口：世界→人物→名册/招贤/任官。名册按朝廷、地方、将领、待选、全部分页和搜索。科举90日/60万两、招贤30日/20万两；每轮登记两位人才，科举受学院等级影响，不保证忠诚，不自动授官。科举结束后360日、招贤结束后30日才可再次举办，这是人才筹备规则，不限制人物交流。
- 默认77座城邑各有长官、副官、主簿。任官25万两/7日，长官能力门槛50，属官35。检查成年、在世、求学、讲席、行在与统军冲突；调任清除原职，前任进入待选名册并有忠诚反馈。履职按能力、忠诚和是否在岗影响地方治安、腐败与民心，记录具体城邑变化；不是自动判罪。旧存档按确定性规则补充属官，不删除旧人物、资金或历史。
- 朝政→宫廷：宫殿、御苑、典籍馆，0–5级，真实拨款、工期、竣工效果及每新增等级2万两季度维护，工程不提前生效。新增宫廷、伴侣与扩编开支进入财政及赤字处理。
- 世界→宗室→选妃：30日/25万两安排成年自荐人士面见；意愿独立记录，明确婉拒者不能登记伴侣；登记15万两/7日，最多4位在世伴侣。登记不打开备孕开关，也不自动怀孕；沿用成年、自愿、健康、关系及独立备孕确认规则。
- 朝政→军政：禁卫军、北境军、行营军，显示真实兵额、驻地、主将、训练、士气、补给与编制战力。支持训练、募兵、调防、任将，分别付费、办理并持久化。募兵受人口和编制上限限制，增加军费、减少民心；季度状态参考主将能力/忠诚/在岗、驻地腐败与财政信用。一个人不能兼领多军，也不能同时担任地方官。

## 保留的边界

人物数值仍属于简化模拟。未实现完整中央六部、科举考生答卷/阅卷舞弊案、逐县税制、全部地方独立案件、婚姻外交、后宫复杂派系、继承与禅让、完整战争/战役/攻城和全部将领战术系统。当前军政界面明确标注战争尚未实现。选妃目前是成人意愿及伴侣登记规则，不是完整宫廷叙事系统。

宗室名册与选妃页也有交流入口：首次交流登记稳定Person映射，保存独立对话，之后同步姓名、年龄、家族身份、生死与关系，避免旧身份复活。家族相处与交谈共用真实家族关系；未成年角色上下文限制为日常、家人与学业。未声称已完成整个世界所有职业和外国人物的完整模拟。

未连接vivo Android16 ARM64真机；不把桌面或x86模拟器模型速度当作手机实测。本地模型可能因上下文、内存、取消或非法角色输出回退，回退明确标记“规则模板”。正式生产签名仍由用户后续提供，私钥不提交仓库。
