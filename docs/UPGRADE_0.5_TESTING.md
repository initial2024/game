# 0.5.0：可点选的州府县、人物互动与国家治理

本版继续在同一个Kotlin/Compose原生游戏中开发。包名`cn.chronicle.shanhe`，versionCode 9；连续时间、暂停和1/4/16/64倍速保持不变。地图仍为用户上传HTML的本地WebView模块，其余游戏操作为原生界面。开发签名沿用已有固定证书，正式生产私钥仍由用户后续提供。

## 可玩的新增内容

- 交流：所有在世登记人物，以及宗室名册/选妃中的家族人士均可打开独立对话。已加载本地模型时使用同一真实推理适配器；失败、无模型时明确标记模板。关系由规则结算，显示信任、忠诚、怀疑与敌意的实际变化；不同内容可有递减收益，重复刷屏不无限增加关系。家族对话同步真实家族关系；姓名、年龄、身份和生死通过稳定映射保存。
- 旨意：从自己的话或人物回复点“拟为旨意”，编辑、预览实际对象/辖区、造价/工期与未执行条款后再确认。支持现有政令、地方工程、派学、任官、科举、招贤、宫廷建设及明确端点的运河。模型文字不直接授予资源或裁判罪行。
- 地图：保留原上传图的地形、旋转缩放、主题、查找等功能。原14府/59县继续存在，增加112个原创县邑，形成4大区、8州、14府、171县、189座国内城邑。州为行政分组；府域和171个县域为规则生成的治理示意，县界放大后显示，避免全图拥挤。不是核验过的真实历史疆域或水文地图。
- 官员：默认573名人物，189座城邑分别配置长官、副官和主簿；人物ID、能力、立场、忠诚、记忆与官职独立保存。未额外复制人口、税源或预算。名册最多1000人，分页与可选搜索；府县按大区→州→府筛选，无需强制打字。
- 人才：科举90日/60万两、公开招贤30日/20万两，每轮两位可实际任官的人才。考核参考学院等级及可保存的种子，忠诚不保证。任官25万两/7日，成年与能力、求学、讲席、统军、组织和行在冲突须通过检查；调任腾空原职，前任及新任有真实反馈。履职影响地方治安、腐败与民心，逐城记录来源。
- 宫廷：朝政→建设→宫廷，可建宫殿、御苑、典籍馆，真实成本/工期/维护费与竣工效果。宗室→选妃登记成年自荐人士的意愿，可面见、交流、自愿登记伴侣或尊重意愿结束相看。登记不会开启备孕或自动怀孕，沿用独立备孕开关与成年、自愿、健康、关系条件。
- 军队：三支军队的兵员、主将、驻地、训练、士气、补给和战力均为数据。支持点选将领、训练、募兵和调防。扩编有财政维护、民心和人口承受限制；将领在岗、能力、忠诚、驻地腐败与财政影响实际状态。
- 战役：朝政→军政→战事，点选军队与国家，宣战办理后动员、交战、停战。交战综合兵力、主将、训练、士气、补给、情报与种子；真实伤亡减少军队和本国人口，军费和厌战持续影响财政、民心。优势达到门槛才可通过停战协议改变已有地图边地/驻点归属，失败可能被迫撤回。不是输入一句话就统一世界。
- 组织：朝政→谍报，可选择监察/谍报/刺客职责、命名、点选驻地，45日/90万两筹建；最多4个组织，每个3名核心成员。成员须单独任用，存在履历、忠诚、费用、任务、暴露及交卸职务规则。
- 谍报：侦察外国可积累真实情报网络，影响后续战役的信息优势；失败可暴露并伤害邦交。反谍降低渗透威胁，威胁较高会发生可追踪破坏。报告写入历史与参与者记忆，不自动认定某官员有罪。
- 杀手组织：游戏内秘密刺杀有成功/失败分支，受成员能力、忠诚、目标治安和组织暴露影响；无论成败损害民心与稳定。成功后清理人物在世状态、官职、统帅、行程、学籍及家族孕期等相关状态，不复活、不凭空判罪。目标仅为游戏登记的在世成年NPC。
- 运河：朝政→建设→运河，点选两个城邑。工程测算成本与120日起的工期，最多12段，有重复/端点/地图状态/跨度检查。竣工才增加交通、商业、农业与沿线属性，并在地图登记蓝色水运连接；每段3万两/季维护，纳入赤字和信用规则。

## 已完成的本地检查

JDK17、Gradle8.13、SDK36/NDK27.2：70项核心测试、Debug和androidTest编译、lint通过。核心覆盖1000季度多种种子/难度/世界模式、重放确定性、人物一致性、关系防重复、旨意预览不执行、任官冲突、真实工期、财政约束、战争胜负/领土/人口、组织/情报/死亡分支、运河线路、旧档扩展与序列化。

浏览器Chromium对390×844、320×720、844×390通过，另验证旧剧情迁移、原生只读、稳定ID选择、增量与错误数据拒绝、自定义地理；原始HTML→补丁→APK资源逐字校验通过。浏览器结果不等于Android或vivo实测。

Actions的ARM64 Release、18项Android界面/API/存档检查和独立真实GGUF测试正在执行，交付前填入真实链接与结果。新增原生闭环包括：无文字点选府县→任官；运河立项→等待竣工→地图线路→进程重启；宣战→交战三次→停战→地图更新；筹建谍报司→任用成员→侦察归报→重启读档。

## 验证边界

本版采用国家级战略战役与示意水运连接，没有战术棋盘、逐街攻城、真实水文勘测或地形施工仿真。州是行政层级分组，尚未实现每州独立税制、全部中央六部、数千名考生答卷、每县完整独立刑案、复杂后宫派系、继承禅让和所有外国职业人物的完整模拟。不能把已完成的可玩闭环称为用户最初全部P2内容均已彻底完成。

未连接vivo Android16 ARM64手机；不声称真机帧率、峰值内存或模型速度达标。真实模型验收使用Android API35 x86_64模拟器、CPU推理，与ARM64 APK构建及桌面浏览器测试明确分开。模型许可/格式/内存失败保持可玩的规则路径，不上传本地存档。
